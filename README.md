# 🚀 FreeCodeCamp JavaScript Certification

Five progressively complex vanilla JavaScript projects. Build from regex parsing to async APIs.

## 📦 Projects

| # | Project | What you build |
|---|---------|---|
| **1** | **Markdown→HTML Converter** | Real-time markdown parser with regex, transform text to HTML instantly |
| **2** | **Drum Machine** | 9-pad drum kit with keyboard + click triggers, audio playback & event handling |
| **3** | **Voting System** | Poll app with Map/Set, prevent duplicates, track results, zero side effects |
| **4** | **Bank Account Manager** | OOP class with transactions, deposits, withdrawals, balance tracking |
| **5** | **Weather App** | Live weather fetcher, async API calls, dropdown cities, formatted data display |

## ⚡ Quick Start

```bash
git clone https://github.com/yourusername/freecodecamp-projects.git
cd freecodecamp-projects/projects/Md-HTML_converter
# Open index.html in browser
```

Each project stands alone, no build tools, no dependencies, just vanilla JavaScript.

## 🛠️ Tech Stack

- **Core:** Vanilla JavaScript (ES6+), HTML5, CSS3
- **Features:** Regex, DOM APIs, Fetch/Promises, Web Audio, Map/Set, OOP Classes

## 📚 What You Learn

✓ Regex & string parsing  
✓ DOM manipulation & event handling  
✓ Async/await & Fetch API  
✓ ES6 collections (Map, Set)  
✓ OOP with classes  
✓ Real-world API integration
